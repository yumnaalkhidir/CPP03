# CPP03

42 School C++ Module 03 — inheritance, including the diamond inheritance problem.

## Concepts covered
- Single, multiple, and virtual inheritance
- The ClapTrap -> ScavTrap/FragTrap -> DiamondTrap hierarchy
- Solving the diamond inheritance problem with virtual inheritance

## Exercises
ex00 ex01 ex02 ex03 

## Build & run
Each exercise has its own Makefile:
```sh
cd exXX
make
./<binary_name>
```
